# Concise Notepad

一款简洁易用、Material风格的记事本应用，使用 Dart / Flutter 开发。

## 特点
- 简洁明了的应用界面体验
- 较为纯粹的 Material Design 体验
- 直观的任务管理和编辑
- 强大的筛选和搜索功能
